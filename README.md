# Saeed Alsuhaimi · Portfolio

Bilingual (Arabic / English) portfolio of Saeed Alsuhaimi, visual artist and digital designer from Makkah.

- `index.html` – the whole site (HTML, CSS and JS in one file)
- `img/` – images
- `vid/` – app animation videos

Static site: open `index.html` or host the folder on GitHub Pages, Netlify or any static host.
